# MY WEBSITE
website buidling is all about creativity, styling and understanding the system one is woking on.
A lightweight static website built with **HTML,CSS,JS**, showcasing three beautiful images of nature.  
This project is a beginner-friendly example of creating and hosting a simple webpage.

---

## ✨ Features
- 📸 Displays three nature images
- 🎨 Styled with basic CSS for a clean look
- 🌐 Easy to host on GitHub Pages

---

## 📂 Project Structure
1. index.html       # Main webpage
2. style.css        # Styling for layout and design
3. script.js        # JavaScript for interactivity
4. images           # Folder containing 3 nature images

---

📖 Learning Goals
- Practice basic HTML structure.
- Apply CSS styling for images and layout.
- Learn how to host static websites online.
